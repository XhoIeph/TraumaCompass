# 方法论

## 1. 项目要回答的问题

ICD-11 把 **复杂性创伤后应激障碍（CPTSD，6B41）** 列为独立诊断，ICD-10 体系中没有对应类目；国内临床诊断书写与医保结算长期以 ICD-10 及医保版编码为主。结果是「符合描述的人拿不到这个诊断」。

本项目用一张全国地图同时呈现两件事：

1. **可及资源**：有官方来源或明确证据支撑的创伤相关服务机构。证据可以是创伤治疗项目（如 EMDR）、
   专科门诊、培训体系或专业指南参编 —— 因此「有证据」**不等于**该机构一定能开出 CPTSD 诊断，
   具体强度记录在 `trauma_service.evidence` 里。
2. **就诊线索**：网友在公开平台上留下的真实就诊路径（医院、科室、医生、流程、费用、体验）。

首期只覆盖 CPTSD 与 BPD。**BPD 不属于「ICD-11 新增」的情形**：ICD-10 有 F60.3，ICD-11 改为「6D10 严重度 + 6D11.x 特质/模式限定词」。收录它是因为它与 CPTSD 存在大量鉴别争议，而不是因为它在 ICD-10 中缺席。

## 2. 两层数据不能混读

| 图层 | 含义 | 不能用来推断 |
| --- | --- | --- |
| 可及资源 | 有官方来源/明确证据的机构数 | 当地真实医疗水平（我们只统计「已核实到的」） |
| 线索密度 | 网友自述线索条数 | 确诊人数、患病率、地区间排名 |

「没有记录」只表示**我们没有收集到可追溯的来源**，不表示当地没有资源。

## 3. 数据来源与采集方式

1. **公开平台内容**（小红书为主源、知乎为副源）：只读取公开可见的笔记/回答/评论。
   通过**已登录的真实浏览器会话**进行检索（OpenCLI Browser Bridge 扩展驱动用户自己的浏览器；
   知乎使用 Playwright + storageState），页面自身完成站点所需签名。
   **不逆向接口、不复现签名算法、不绕过风控、不采集私信或任何非公开内容。**
2. **官方来源**：医院官网、国家及地方卫生健康委公开信息、医院等级与执业信息公示。
3. **公开网页与用户提交**：新闻、科普文章、GitHub Issue 提交的公开来源。

采集节奏与停止条件见 [collection-runbook.md](./collection-runbook.md)：**不设数量上限**，只在两种情况下停止 —— ① 平台出现登录墙/验证码/限流；② 连续多轮检索不再产出高相关度新内容（饱和）。节奏保持人类尺度（单线程、单标签页、自然间隔）。

## 4. 核验等级

| 等级 | 判定标准 |
| --- | --- |
| `official` 官方来源 | 至少一个官方来源（医院官网/卫健委等）可核实该条陈述中的客观事实 |
| `corroborated` 多源印证 | 两条及以上**相互独立**的公开线索指向同一事实，但无官方来源 |
| `unverified` 未核实 | 单条网友自述，仅作线索 |

规则：**没有官方来源的陈述永远不会被标成 `official`**；机构与医生的客观信息（名称、科室、职称）必须有官方来源才会建立条目。

## 5. 收录与排除标准

收录：
- 公开可访问的原帖链接 + 逐字摘录（≤200 字）。
- 至少能确定：平台、疾病条目、就诊阶段。

排除（命中即 `withheld`，保留记录编号但内容下线）：
- 涉及未成年人的可识别信息（姓名、学校、住址、照片）。
- 自伤/自杀的方式、剂量、工具等细节。
- 病历号、就诊卡号、身份证号、联系方式、住址门牌。
- 私聊、群聊、付费社群内的非公开内容。
- 无法追溯来源的转述（「我朋友说」且无原帖）。

## 6. 聚合口径

- 省份归属优先级：① 关联机构的所在省 → ② 作者自述地区文本 → ③ 平台 IP 属地文本。
  三者含义不同，页面上必须分别标注来源。
- 作者自述地区与 IP 属地都只是**文本匹配**，可能误判；`npm run data:stats` 会打印「未定位省份」条数。
- 同一原帖只计一次（按规范化链接去重）。

## 7. 更新节奏与已知局限

- 数据以构建产物形式发布：`npm run data:build` → `next build` → 静态站点。
- 来源可达性定期巡检：`npm run audit:sources -- --write`；失效线索应改为 `withheld`。
- 已知局限：
  - 图文笔记的正文可能在图片里，首期不做 OCR。
  - 小红书原帖链接含会过期的 `xsec_token`，公开数据只保留规范链接（`/explore/<note_id>`）。
  - 样本量小、地域分布不均，任何比较性结论都不成立。
  - 平台反爬策略变化可能导致采集通道失效，届时降级为人工录入，**字段标准不降**。
