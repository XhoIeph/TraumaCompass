## 滚轮停顿返修

- 原因：320ms 内直接丢弃滚轮事件；`setZoomAround` 也不能接续已有的 CSS 缩放动画。旧测试只确认了节流生效，没覆盖用户要求的连续接续。
- 新控制器 `lib/map-wheel-zoom.ts` 按动画帧合并输入，通过 Leaflet 原生 `flyTo` 从当前画面接续目标，不先 `stop()` 吸附回整数级。目标保持整数且限制领先距离，避免累积出长时间追赶的队列；换向不等待旧方向结束。
- 保留鼠标锚点、缩放上下限、Ctrl/横向手势和减少动态效果。拖拽、定位、回到全国及卸载会清理待执行输入。
- `npm run test:map-wheel`：5 项回归通过，特意验证 16ms 后的新输入仍被处理，以及换向、锚点、边界、帧合并、清理。
- 本轮成功使用浏览器的滚轮输入接口。在约 0.5 秒内连续发送五组输入，采样到图层在动画途中持续缩放；松手后两个活动瓦片层均为 `scale(1)`，且无待加载瓦片。截图：`07-wheel-retarget-stopped.png`。
- `npm run build`、`npm run typecheck` 再次通过。线索和来源内容未改动。工具输入与用户实体鼠标/触控板仍有差别，最终手感等待用户确认。
