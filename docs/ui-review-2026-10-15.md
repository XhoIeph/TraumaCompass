## 其他修改与验证

- 滚轮保留整数瓦片级别、每次最多一级；修复页面刚加载时首个手势被节流吞掉的问题。Ctrl＋滚轮留给浏览器，横向触控板不触发地图缩放，尊重减少动态效果设置。
- 对实际滚轮回调做离线桩测试，覆盖首次输入、连续输入节流、小增量累积、Ctrl、横向手势、减少动态效果和最小缩放边界，全部通过。工具没有实际鼠标滚轮注入接口，不能把这些测试称为真实鼠标手感验收。
- 补齐移动浏览按钮、清除搜索按钮等反馈。保留现有 GSAP 面板动画，不用 GSAP 或全局 CSS 改写 Leaflet 的图层 transform。
- 删除医院/线索页标题旁重复的介绍句；不删来源、原文、图例中密度和坐标的必要说明。
- `npm run build`（含数据校验）及 `npm run typecheck` 通过。68 条缺少医院官方来源的既有提醒保留，不属于本轮数据修订。
- 构建只改了聚合文件生成时间，已还原该时间；`data/curated/reports.json`、`data/generated/province-stats.json`、`lib/format.ts` 与上个检查点保持一致。
