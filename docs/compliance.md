# 合规、伦理与风险控制

本项目收集的是**精神健康**相关的第三方内容，并会对可识别的医疗机构与医生做公开呈现。
以下规则是硬约束，任何一条与「多收数据」冲突时，以本节为准。

## 1. 个人信息（《个人信息保护法》）

- **最小化**：只收集与「就诊路径」直接相关的字段；不收集身份证号、病历号、就诊卡号、联系方式、住址门牌。
- **不记录用户标识**：昵称、账号、IP 属地一律不采集、不保存（早期版本做过哈希别名，已全部移除）；
  原始昵称只允许存在于本地 `data/raw/`（已在 `.gitignore` 中），不推送、不随站点发布。
- **敏感个人信息**：精神健康状况属敏感个人信息。本站不建立任何个人档案，只保留单条公开自述的摘录与链接；
  不把同一作者的多条内容聚类成个人画像。
- **不采集非公开内容**：私信、群聊、付费社群、仅好友可见内容一律不采。
- **未成年人**：涉及未成年人的可识别信息不得发布（`contains_minor: true` 强制 `withheld`）。

## 2. 名誉权与对医生的公平性

- 医生条目只写**公开执业信息**（姓名、科室、职称、专长），来源限于医院官网或国家卫健委执业注册信息查询。
- 网友评价只以**逐字摘录 + 原帖链接 + 上下文**形式呈现，不作真伪判定，也不作为事实陈述。
- **不以负面评价作为排序、推荐或突出展示的依据**；不做「黑榜」「避雷榜」。
- 对同一机构的正面与负面线索采用同一展示规则与同一核验标准。
- 提供撤下与更正通道，并在数据中保留处理痕迹（见 [takedown.md](./takedown.md)）。

## 3. 医疗与广告合规

- 全站声明**不构成医疗建议**，不做诊断、治疗、用药推荐。
- **不接付费排名、导流、软文、机构合作推广**；首版无任何商业化。
- 不做疗效承诺、不使用「治愈率」「最好」等表述。
- 危机资源常驻：全国统一心理援助热线 **12356**（国家卫生健康委统一号码）。

## 4. 地图合规

- 首版底图为**示意性质的非标准地图**（DataV GeoAtlas 省级边界），页面明确标注「非标准地图」。
- **公开宣传或正式发布前**，须替换为自然资源部标准地图服务底图，并标注审图号（形如 GS(年份)xxxx号）。
- 地图按省级着色，首版不标注机构坐标点，避免把线索定位到医院门牌造成误导。

## 5. 平台规则与采集边界

- 只读取公开可见页面；通过用户已登录的真实浏览器会话进行，页面自身完成站点签名。
- **不逆向接口、不复现签名算法、不注入指纹、不绕验证码、不换 IP 规避限制**。
- **本项目不设采集数量上限**（2026-09-11 起，按项目所有者要求取消所有自设配额）。
  `npm run collect:quota` 现在只是**用量统计**，永远不会拒绝调用。
  真正需要停下来的信号只有两个：
  1. **平台侧异常**：出现登录墙、验证码、限流页或连续异常返回 —— 立即停止本轮并记录；
  2. **饱和**：连续多轮检索不再产出高相关度的新笔记与评论。
- 节奏仍然保持人类尺度（命令之间自然间隔、单线程、单标签页），这是账号安全纪律，不是配额。
- 采集规模较大时**建议使用小号**；`.secrets/quota.json` 里保留了每日调用计数供复盘。

## 6. 风险登记

| 风险 | 影响 | 处置 |
| --- | --- | --- |
| 平台风控 / 账号被限制 | 采集中断，账号风险 | 人类节奏、单线程、熔断即停；规模大时用小号 |
| 原帖被删除 | 链接失效、可核查性下降 | `npm run audit:sources` 巡检，失效改 `withheld` |
| 把自述地区误当就诊地 | 结论失真 | 地区只分「医院所在地」与「作者自述所在地」两类，页面上分别标注；IP 属地不采集 |
| 线索含负面指控 | 名誉权风险 | 逐字摘录 + 原帖链接 + 撤下通道；不作真伪判定，负面评价不参与排序 |
| 用户提交隐私内容 | 违法风险 | Issue 模板前置警告 + 人工复核 + 立即下线 |
| 编码写错（尤其 BPD/ICD-11） | 专业性受损 | `code_review_status` 标记；上线前在 WHO ICD-11 浏览器逐条核对 |

## 7. 数据许可与再使用

- 代码与数据结构：Apache-2.0。
- 线索摘录：版权属于原作者，本站只做**有限引用**（≤200 字）并附原帖链接；不转载全文、不镜像图片。
- 任何人发现本站内容侵犯其权利，可通过 Issue 申请撤下。
